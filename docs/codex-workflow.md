# AI-assisted delivery workflow

The provider-neutral Sniffy delivery model moved to [`docs/ai-delivery/`](ai-delivery/README.md).

Use:

- [`ai-delivery/routing.md`](ai-delivery/routing.md) to choose ChatGPT, Codex Cloud, Local Codex, an IDE agent, or a human;
- [`ai-delivery/supervision.md`](ai-delivery/supervision.md) for delivery states, dispatch proof, monitoring, review, and merge
  boundaries;
- [`ai-delivery/verification.md`](ai-delivery/verification.md) for exact-head proof and verification ownership;
- [`ai-delivery/executors/codex-cloud.md`](ai-delivery/executors/codex-cloud.md) for Codex Cloud setup and publication;
- [`ai-delivery/executors/codex-local.md`](ai-delivery/executors/codex-local.md) and
  [`local-codex-worker.md`](local-codex-worker.md) for the app-native local worker.

This compatibility entry point remains so historical pull requests, skills, and external links do not silently break. New
policy and links should use `docs/ai-delivery/` directly.
