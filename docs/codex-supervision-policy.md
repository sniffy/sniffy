# AI delivery supervision policy

The current provider-neutral supervision policy lives in
[`docs/ai-delivery/supervision.md`](ai-delivery/supervision.md).

That policy applies to ChatGPT, Codex Cloud, Local Codex, IDE-hosted agents, other implementation agents, and human-led
autonomous delivery. It defines executor identity, delivery states, 15-minute/15-minute/hourly monitoring, branch and PR
continuity, exact-head review, formal-review identity, and the no-merge boundary.

This file remains as a compatibility entry point for historical links. New references should use the canonical path above.
